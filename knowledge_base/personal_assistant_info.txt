Основная цель этого проекта - создать персонального AI-ассистента для Telegram.
Ассистент должен уметь управлять задачами через Google Tasks, работать с расписанием в Google Calendar и искать информацию в интернете.
Проект использует микросервисную архитектуру 'Agent-Tool Gateway'.
Ядро агента построено на LangChain, а в качестве LLM используется локальная модель gemma:2b через Ollama.
Память диалогов хранится в Redis. Векторная база знаний реализована на ChromaDB.
Инструменты предоставляются через отдельный MCP-сервер.
